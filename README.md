## What is it?
This is a remake/redo of the Merbl Run with my own customisation!

The design includes 3 different obstacles as well as the ability for marble races and multiplayer battels!

## What can you do with it?
### Single Marble Use:
Place one marble at any one of the 2 holes and drop it, watch it fall through and if you want use a timer to see how quick it can go!

### Multiplayer Battels:
Use 2 Different Colour marbles (or mark them with different colours/symbols) and then hold them at the 2 start holes. 3, 2, 1 GO! Drop them both at the same time and watch them battel it out for 1st place! You could keep score of who is winning or just play for fun!

### Rampage!
Grab a lode of marbles and as quick as possible (or get someone to help) put them all into the run using both starting holes! See the chaos unfold!
